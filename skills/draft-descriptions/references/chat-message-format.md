# Сообщения для командного чата

Это форматы кнопок «Сообщение УЗС … для чата» и «Сообщение КЗС для чата» в IVA Git Flow Bot. Они отличаются от содержимого описания MR.

УЗС — три строки:

```text
Сливаю УЗС-[номер в серии]: [краткий итог]
[ссылка на УЗС]
√[добавлено строк],💀, [целевая ветка] >= 2, тест ([длительность] сек)
```

КЗС — две строки:

```text
КЗС: [ссылка на КЗС]
√[добавлено строк], [целевая ветка], >=2
```

Если есть реальная демонстрация результата, последняя строка КЗС заканчивается `, демо`.

Номер УЗС — его позиция в серии, начиная с 1; это не GitLab IID. Краткий итог — одна фраза о результате именно выбранного УЗС. Не вставляй длинный заголовок с номерами Jira/MR и маркерами. `√` содержит число добавленных строк именно этого MR. У КЗС с пустыми коммитами оно может быть 0; при недоступном или неполном diff число неизвестно, а не 0.

Порог коммитов всегда записывается `>= 2` для УЗС и `>=2` для КЗС. Время теста указывают в секундах только при подтверждённой длительности. Если тест не запускался, напиши `тест (не запускался)`; если сведений нет, оставь `[длительность]`. Случайное число из старого генератора бота не является результатом проверки.

Неизвестные значения в квадратных скобках — места для заполнения. Отсутствующая ссылка не означает поручение создать MR. Сам текст сообщения не отправляется коллегам и не выполняет слияние.
